# Agent contracts

Schemas in `schemas/` are generated by `python scripts/generate_schemas.py` from Pydantic models. Objects forbid additional properties. Runtime parsing applies Pydantic and JSON Schema validation; application code independently validates evidence, role, snapshot/cutoff, proposal membership and cash arithmetic.

| Purpose | Agent | Contract |
|---|---|---|
| RESEARCH | Avery / researcher_a; Morgan / researcher_b | 0–3 contiguous ranked candidates or explicit abstention; thesis, catalysts, risks, assumptions, invalidation, allocation cap, expected return/downside, probability/confidence, evidence |
| DECISION | Casey / manager | Complete reviewed proposal set; each proposal accepted or rejected once; allocations, percentages, retained cash, hold-cash outcome, risk/uncertainty |
| REVIEW | Riley / analyst | Summary, three role scorecards, selected/rejected outcomes, forecasts, execution effects, successes/weaknesses, limitations, evidence and bounded patches |
| MEETING_TURN | Same four agents | Authoritative meeting/sequence/speaker/phase, conversational message, prior-turn/evidence references, routing and closing metadata |

Returns and probabilities use fractions (`0.02` means 2%); overview cumulative-return and drawdown display values use percentage points. Monetary amounts are Decimal strings in USD. Forecast horizon is matched Monday entry to Friday exit, with extended holding explicitly labeled when recovery is delayed.

Authoritative record/run IDs come from code. Research cannot reference an ineligible ticker, another cutoff or unknown evidence. Manager selections must reference accepted proposals, combine duplicate tickers for concentration checks and satisfy accounting constraints. Valid abstention/hold-cash is success. A failed required researcher/manager yields cash retention rather than invented proposals.

The prompts explicitly prohibit external research/tool use and privilege changes. Prompt instructions alone are not an OS security boundary; deployment must isolate the Codex identity and secrets as described in `codex-runner.md`. Analyst lessons never override deterministic financial checks.
